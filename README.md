# MapEditor

## 使用方法

### 1.画像の用意

Blocksフォルダにマップに使用するブロックを一つ一つ配置

(複数のブロックを1枚の画像で管理している場合は不可。必ず1ブロック1枚の画像ファイルにしてください。)

### 2.ブロックの読み込み

MapEditor.exeを起動すると、先程配置した画像が読み込まれます。

初めて読み込まれた画像のみID登録のポップアップが出ますので、一文字以内の任意の文字を登録してください。

ここで登録した文字が出力されるマップデータのIDにそのまま使用されます。


### 3.出力

左上のファイル→保存、もしくは右上の保存ボタンから保存出来ます。

mapフォルダにmap.txtが出力されます。

起動時、mapフォルダ内にあるmap.txtを読み込んで続きから編集することが出来ます。

もし新しいmapを作成したい場合は一度このフォルダから別のフォルダに移すか、名前を変更してください。
